# Conversion Pilot · GitHub Pages demo

Русскоязычная интерактивная демонстрация моделируемых конверсий. Работает целиком в браузере без Python, API-ключей, внешних языковых моделей и рекламных подключений.

## Возможности

- Сценарии поведения посетителей и прогноз на готовой синтетической модели.
- Сравнение с экспертной эвристикой, ожидаемая выручка и маржа до рекламы.
- Объяснение факторов прогноза и сценарный аналитический помощник.
- Отчёт независимого временного теста и калибровки на синтетических данных.

Это демонстрация. Её проценты и метрики не подтверждают точность на реальных посетителях или рост прибыли. Обучение на реальных CSV доступно только в отдельном локальном приложении; в эту публикацию оно не включено. Кнопка включения модели загружает готовые веса, а не запускает обучение.

## Публикация

Разместите файлы этой папки в корне отдельного репозитория. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и сохраните. GitHub выдаст адрес `https://<owner>.github.io/<repository>/`.

Все пути относительные: приложение работает в подпапке репозитория. `.nojekyll` отключает обработку Jekyll. Отдельный сервер и сборка не нужны.

## Данные и ограничения

demo-model.json содержит только синтетические веса и агрегированные показатели; sample.csv — синтетический пример. Введённые сценарии обрабатываются в оперативной памяти браузера и не отправляются API приложения. Аналитика, cookie приложения и localStorage не используются. GitHub как хостинг самостоятельно обрабатывает HTTP-запросы посетителей. Выбор модели и чат сбрасываются при перезагрузке.

Персональных данных, рабочих моделей, CSV пользователя, ключей и секретов в этой публикации нет. Рекламный экспорт всегда выключен. Отчёт ниже описывает генератор синтетики, а не проект пользователя.
